# T7 Cost Model

Primary performance metric is net INR P&L.

Each trade has four entry orders and four exit orders.

Costs include:
- adverse 2-point option premium slippage on every executed leg;
- brokerage stress at ₹10/₹20/₹30 per executed F&O order;
- option-sale STT using historical execution date;
- historical NIFTY lot size.

No gross result is used as the primary final performance metric.
